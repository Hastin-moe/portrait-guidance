# 器材发光 / 运行参数出处

> 目录 JSON 的 `refs` 字段指向本文件的文献 id。数值均为厂商标称；**不是**计量实验室证书。照度 / f-stop 条件（距离、ISO、修饰器、色温）以各条为准。

## 通用方法说明

| id | 说明 |
|---|---|
| `method-flash-fstop` | 影室闪光常用「2 m · ISO 100 · 指定反光罩」下的光圈值（Broncolor 技术表惯例）。可按 \(E \propto 1/d^2\) 粗推其他距离，但修饰器改变配光后不适用。 |
| `method-led-lux` | LED 持续光常用厂商在指定修饰器、色温下的 lux（多为 1 m）。与闪光 GN / f-stop **不可直接互换**。 |
| `method-guide-number` | 指南数 GN（米，ISO 100）：\(GN \approx N \times d\)（米）。厂商「efficient reflector」条件不同，跨品牌勿直接对比。 |

## 照度 / 曝光换算备注

1. **Broncolor f-stop 表**（Siros / Satos / Move）：条件固定为 **2 m · ISO 100 · 指定反光罩**（常见 L40 / P70 / MobiLED+P70）。见 `bron-siros-*-tds`、`bron-satos-tds-2024`、`bron-move-1200l-tds`。
2. **Beauty Dish**：官方旧表给出 3200 J · 2 m · ISO 100 下无/有漫射布约 **f/32.6 / f/32.1**（`bron-beauty-dish-tds`）。
3. **LED F160 相对光效表**：同一灯头换修饰器时的相对 f-stop（`bron-led-f160-photometry`）；用于比较光效器材效率，**不是**闪光绝对照度。
4. **Godox LED lux**：ML100Bi / SL60II* 等为厂商标称 lux@距离（`godox-ml100bi-za`、`godox-continuous-catalogue-en`）。
5. **Godox 闪光 GN**：AD 系列多为「efficient reflector · ISO 100 · 米」；AD100Pro II 官方 Tech Specs **未公布 GN**。
