## 3. 意见逐条展开

### 3.1 通用：二级编辑层（T17）

点任何条目（模特、造型、情绪板图片、动作、器材、镜头、场地图元素）都打开**二级编辑层**。它盖在主工作区上，左上有「‹ 返回」和面包屑，右侧面板保留为摘要和检查。

```
┌─ 顶栏 ───────────────────────────────────────────────────────────┐
│ ‹ 返回  模特与样图 / 林夏                          上一位 ‹ › 下一位 │
├──────────┬───────────────────────────────────────────┬──────────┤
│ 步骤导航 │ [基本信息] [工作照] [服装] [角色] [付费选项] │ 摘要      │
│          │                                           │ 检查      │
│          │  表单：两列，窄窗口自动变一列               │ 被哪些镜头 │
│          │                                           │ 用到      │
└──────────┴───────────────────────────────────────────┴──────────┘
```

- **打开方式**：单击卡片、双击场地图元素、或选中后按 Enter；Esc 或「‹ 返回」关闭。
- **窄窗口**：小于 1440 px 时右侧摘要收起，**编辑层本身不受影响**。
- **地址**：编辑层要能写进地址栏，例如 `#/p/<id>/models/<personId>`，刷新后还在原处。

### 3.2 S3 模特档案（意见一，T18、T19）

**二级编辑层的五个标签页：**

| 服装 | 把现在的「造型」扩成**服装套组**：套组名、单品清单（上装 / 下装 / 外套 / 鞋 / 配饰，每件写颜色和材质）、来源（自备 / 租借 / 工作室 / 品牌方）、负责人、状态（待准备 / 已备好 / 已到场）、照片 | 套组就是现在的 look，S5 分镜照常引用 |

| 付费选项 | 开关「付费模特」；打开后出现下面三组 | 见下 |

**付费选项（T19）：**

- **工作时间**：约定的到场、开工、收工时间；午休；超时怎么算（按小时价或不计）。S7 时间轴超出这个时间时提示。

  - **走位**：在 S6 场地图上画路线（见 3.6）。档案里只显示「已画 n 条，查看」。
- **MCN 登记**（按 Q4）：机构名称、经纪人与联系方式、合同 / 授权编号、肖像授权（用途、平台、期限）、费用与结算方式、备注。

**新增检查项：**
- 付费模特没填工作时间；

- 镜头用到的服装套组状态还是「待准备」；

### 3.5 参考图获取（T22，S3 / S4 / S5 共用）

一个「添加参考图」弹窗，五个入口：

1. **上传**：选文件，或拖进窗口。
2. **粘贴**：⌘V 粘贴剪贴板里的图片。在浏览器里「复制图片」后直接粘贴。
3. **搜索**（Q1-A）：输入关键词（自动带上项目风格关键词），选平台，点「去搜索」在浏览器打开结果页。看中的图拖回或粘贴回来，程序会让你填来源链接。
4. **从情绪板选**：只在 S4、S5 出现。
5. **AI 生成**（Q2-A）：写描述（自动带上项目风格关键词、景别、动作要点）→ 显示张数和预估费用 → 确认后生成。没填 API Key 时按钮是灰的，并提示去设置里填。

每张图都记录来源（上传 / 粘贴 / 搜索平台 / AI 生成）和来源链接。AI 生成的图左下角固定标「AI」。

### 3.6 S6 场地图（图 5，T23、T24）

**① 修改都进二级菜单（T17 的场地图版）**

画布上单击元素只选中，并在元素旁边弹出一行**快捷条**：旋转 ±15°、复制、删除、「编辑…」。双击元素、按 Enter 或点「编辑…」打开二级编辑层。

灯的二级编辑层有五个标签页：

| 标签页 | 内容 |
|---|---|
| 位置 | X、Y、灯高（m）、水平朝向（°）、俯仰角（°）；可以「对准被摄者」一键朝向 |
| 灯头 | 绑定器材清单里的灯；显示目录参数（功率、闪光指数或 1 m 照度、色温、显色） |
| 光效 | 光效附件**合成一个列表**：修饰器（柔光箱 / 抛物线 / 雷达罩 / 伞 / 标准罩……）、蜂巢（角度）、柔光布层数、色片 / 色温、遮扉。光束角跟着修饰器自动带出，也可以手改 |
| 光强 | 功率档（Q6）、估算的脸部光圈或照度（沿用 EX 的算法）、测光读数 |
| 关系 | 下面 ② 的全部数据，表格形式 |

画布上的灯图标按「灯头 + 修饰器」画成一个整体：修饰器的真实开口宽度画在灯前，光束扇形从修饰器开口发出，不再是灯和修饰器两个分开的东西。

**② 详细数据和相对角度实时显示（T24）**

选中或拖动元素时，画布上实时画出下面这些，拖动中也跟着变：

| 选中的是 | 实时显示 |
|---|---|
| 灯 | 到被摄者的距离（按灯高算的斜距）；**相对被摄者朝向的水平角**（0° 正面光，45° 伦勃朗，90° 侧光，135° 侧逆光，180° 逆光；标出左 / 右）；**相对机位轴线的角度**；**高度角**（灯高和俯仰算出光从多高打到脸）；到背景的距离 |
| 机位 | 到被摄者的距离；相对被摄者朝向的角度（正面 / 3/4 侧 / 侧面）；按焦段估算的画面高度，例如「85 mm 在 2.4 m 约拍到半身」 |
| 人物 | 朝向；到背景的距离；面前每盏灯的水平角，以小扇形标注 |

**画法**：被摄者为圆心画一段弧和角度数字，类似量角器。角度旁写光位名称（正面光、伦勃朗、侧光……）。

**③ 走位（T19 的场地图部分）**

工具栏加「走位」工具：选一位模特，在画布上点出路线，包括起点、停留点（可写停留秒数和动作）和终点。路线可以挂到一个或几个镜头。S8 进度看板的镜头卡上显示走位缩略图。
